先守住第一段时间

刚登陆的新 PR

你最先要弄清的不是枫叶卡何时到期，而是首个五年还能怎样安排、税务居民从哪一天开始、所在省医保要求你实际住多久。

按这个顺序做

  1. 把成为 PR、开始在加拿大生活和每次出入境的日期放进天数总账，先找最紧的一把尺子。
  2. 把住房、配偶子女所在地、工作与主要账户列在同一页，报税前确认居民起始日。
  3. 离境前分别向 IRCC 与省医保核对，不用一张仍有效的枫叶卡推断居住义务或医保资格。

什么时候不要自己猜

如果首次报税同时有境外收入、资产或两地住房，找熟悉跨境居民身份的 CPA；如果要主张境外天数例外，找持牌移民律师或顾问核证据。
