# 枫居罗盘

加拿大身份、税务、福利与长远规划的本地决策工具站。一份出入境记录同时放进 PR、入籍、税务天数、省医保与 OAS 五把尺子，再生成未来五年时间线。

- 所有个人日期都在浏览器内计算，不上传。
- 所有公开数字只读 `data/rules.json` 中的 `verified` 条目。
- 税务居民、PR 例外、离境税与国籍后果只给整理与估算，不作个案裁决。

```bash
npm install
npm run check
```

第一版规则核读与设计取舍见 `REPORT-build-1001.md`；家庭文件、规则版本、医保/OAS/CBSA 修正、题库复判准备与第二轮上线证据见 `REPORT-round2-1001.md`。
