真正要处理的是居住义务缺口与旅行位置：人在加拿大、人在境外、是否已有正式认定，会把路径分成完全不同的三条。

按这个顺序做

  1. 先按完整行程算缺口，并区分成为 PR 未满五年与已满五年。
  2. 人在境外需要旅行文件时读 PRTD 路径；人在加拿大不要把续卡申请当成自动补救。
  3. 把人道与同情因素、儿童最佳利益和境外例外的原始证据按日期整理。

什么时候不要自己猜

已收到居住义务认定、离境后无法登机、或要主张人道理由时，尽快找持牌移民律师。
