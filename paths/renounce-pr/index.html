先把身份和税务拆开

准备主动放弃 PR

放弃 PR 解决的是移民身份，不会自动终止加拿大税务居民身份，也不会替你完成离境税申报。

按这个顺序做

  1. 先比较保留、PRTD 与自愿放弃三条路，确认以后以什么身份来加拿大。
  2. 按 IRCC 现行表格与材料清单准备放弃申请，并保留完整副本与送达记录。
  3. 另做税务居民问卷和离境税估算，把资产公允市值、成本与离境日期单独留档。

什么时候不要自己猜
