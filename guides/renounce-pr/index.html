自愿放弃 PR：IMM 5782 怎么交、批准那天起身份怎么变、之后回加拿大要什么签证

放弃 PR 不收费、批准即生效且不能上诉；之后持中国护照来加要办访客签证，税务居民身份另算

自愿放弃永久居民身份，用的是 IMM 5782 申请表，配 IMM 5783 文件清单，不收申请费。官员批准那天起你就不再是永久居民，这个决定不能向移民上诉庭上诉；正在处理的入籍申请会被拒，在办的家庭团聚担保会被暂停，配偶和孩子不必随你一起放弃。

如果批准当天你人在加拿大，且申请不是在入境口岸提交的，你会自动变成为期六个月的临时居民，不能再未经许可工作或学习。之后来加拿大，持中国护照要申请访客签证。

项目 数字或表格
申请表 IMM 5782
文件清单 IMM 5783
申请费 0
批准时在境内的临时居民期 6 个月
访客签证费（每人） 100 加元

最容易错的两点：一是以为放弃 PR 就自动成了加拿大税务非居民，其实税务居民身份看的是居所联系，与移民身份是两套规则；二是天数其实还够、或者离入籍只差几个月，却因为怕被查而主动放弃，把可以保住的身份提前交了出去。

决定之前先问自己一个问题：未来几年是否真要回来常住。要回来，就把力气花在人道理由和尽快回来上；不回来，放弃比拖着更省事，探亲入境也更可预期。

已经确定不回来常住、天数早已不够又需要常来探亲，或者要去别国入籍或任职、对方要求先放弃加拿大 PR 的，应读完整详解。
