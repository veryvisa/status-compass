赵女士 58 岁，2016 年 5 月 1 日以技术移民身份登陆，在本拿比住到 2019 年 7 月 1 日，回杭州照顾父母后就没再长住。女儿在温哥华工作结婚。她 2024 年底回来过一次，住了不到四周。现在她想得很清楚：不打算再回加拿大生活，只想每年来看女儿。问题是，枫叶卡早过期了，要不要先放弃 PR？放弃以后，本拿比那套出租的公寓和 RRSP 怎么办？

想主动放弃 PR 的，通常是这几种人：像赵女士这样早已回国定居、天数远远不够的；在中国或美国有了稳定工作、确定不回来的年轻人；准备加入另一个国家国籍、不再需要加拿大身份的。共同点是：他们以为放弃 PR 是「收尾」，其实它只收了移民这一头。

先后顺序

  1. 先确认以后用什么身份来加拿大、家人以后会不会需要你回来常住。
  2. 再理清税务：哪年成为非居民、离境年报没报、出租房产与账户怎么处理。
  3. 然后才递交放弃申请，并保存完整副本。
  4. 最后通知银行、券商与各类付款方你的非居民身份。

对这类人先到线的是哪几把尺子

移民这一头，天数早已不是要算的问题，要算的是「以后用什么身份来加拿大」。自愿放弃 PR 用 IMM 5782 申请 来源，材料清单是 IMM 5783。来源 放弃后，以中国护照来加拿大要按外国访客办理，不能再凭 PR 身份入境。

税务这一头才是真正要算的。CRA 说，你通常在以下几个日期中最晚的那天成为非居民：你离开加拿大的那天、配偶和受抚养人离开的那天、你成为新居住国居民的那天。来源 也就是说，赵女士的税务离境日大概率是 2019 年，而不是她签 IMM 5782 的那天。放弃 PR 不会改变这件事，也不会替她补上当年该报的东西。

赵女士的完整算例

先算移民。规则：出境日与入境日都算在加拿大，看计算日往前的滚动五年，算法见算法说明。窗口 2021-10-02 到 2026-10-01 里，她只有 2024-12-20 到 2025-01-15 这一段在加拿大，共 27 天，离 730 天差 703 天。以人道理由申请 PRTD 的空间很小，而她本人也不想再住回来，这是放弃路线合理的前提。

再算税务。假设她 2019-07-01 离开时名下有：一套本拿比公寓（出租）、RRSP 约 6 万加元、一个普通投资账户，内有加拿大银行股成本 3 万、当日市值 4.2 万，美国指数基金成本 2 万、当日市值 2.6 万。

第一步，哪些不算视同处置。加拿大境内的不动产、RRSP、TFSA、RESP 和养老金计划等，不属于离境时视同出售的财产。来源 公寓和 RRSP 都不在这一步。

还有一条对短期居民很重要：离境前十年内在加拿大居住合计不超过 60 个月的人，最后一次成为居民时已拥有（或之后继承）的财产也不视同处置。来源 赵女士在加拿大只住了约 38 个月，符合这个条件；但普通账户里的两只证券是登陆后才买的，用不上这条。如果她在中国就持有的股票带到了加拿大，那部分可以排除。

第二步，哪些要视同出售。普通账户里的两只证券要按离境日公允市值视同出售再买回。来源 银行股收益 4.2 万 − 3 万 = 1.2 万；基金收益 2.6 万 − 2 万 = 0.6 万；合计资本利得 1.8 万加元，用 T1243 计算申报。来源

第三步，要不要填 T1161。离境时所拥有财产的公允市值合计超过 25,000 加元，通常要填 T1161 申报财产清单。来源 她仅普通账户就有 6.8 万，哪些项目可以排除在门槛之外要逐项核，但大概率要填。

第四步，要补的是什么。如果她 2019 年没有报离境年税表，问题不是放弃 PR 能解决的。这一年要按离境日之前的居民期申报，并处理上面的视同处置；此后每年公寓的租金，作为非居民也有预扣和申报义务。具体数额与补报方式，见离境税专题。

三条路放在一起比

赵女士的选择不止「放弃」一种。把三条路放在一张表上，比较的是以后用什么身份来、要付出什么：

路线 适合谁 主要代价 以后来加拿大
继续保留、不动 近一两年内确定回来常住的人 卡已过期，人在境外回不来；身份处在随时可能被认定的状态 要先拿到旅行证件
申请 PRTD 有强人道理由、确实打算回来生活的人 证据准备重，被拒后进入认定与上诉程序 获批后以 PR 回来，要尽快补天数
自愿放弃 确定不回来生活、只想探亲的人 不可撤回，以后只能重新移民 以访客身份，按规定办签证

对赵女士这样天数只有 27 天、又不打算回来的人，放弃往往是成本最低的一条路：它让她不必再面对一个注定通不过的审查，以后办探亲签证时，也能如实说明身份已经主动了结。

但放弃之前，要先把一件事想清楚：女儿在加拿大，她以后有没有可能想来常住。父母类的移民名额有限、排期很长，主动放弃一个现成的 PR，等于放弃了最直接的那条路。这个问题在家庭里商量清楚，比任何表格都重要。

中国这一头，她一直是中国公民，在杭州的户口、医保、养老待遇不受放弃加拿大 PR 的影响。如果早年因出国定居注销过户口，回国定居要按户籍地的规定申请恢复，各地要求不同。

按时间排的行动表

今天：用路径判断树比较三条路：继续保留（等于在境外持有一个大概率无法续的身份）、申请 PRTD、自愿放弃。用离境税估算器把离境日的资产按「视同处置／不处置」分开。

放弃之前：先把税务这一头理清，包括离境年税表有没有报、出租房产的非居民申报做没做、TFSA 在离境后有没有再存钱。非居民存入 TFSA 的部分每月按 1% 计税，直到取出或恢复居民身份。来源

递交 IMM 5782：按 IMM 5783 清单准备，保留签字申请、证件副本和递交记录的完整副本，细节见自愿放弃 PR 专题。

放弃之后：以访客身份来加拿大前办好签证；通知加拿大的银行和券商你是非居民；继续按时处理租金的非居民申报。

以后想回来常住：放弃 PR 后不能撤回，回来只能重新走移民程序，父母类通常是团聚类别或超级签证这类临时身份。

最常见的误区

误区一：「放弃 PR 就不用跟 CRA 打交道了」。税务居民身份看的是居所联系与离境日，不看移民身份。你可能早已是非居民，也可能因为在加拿大留着住所和配偶而仍是居民。

误区二：「离境税是放弃 PR 那天算的」。视同处置发生在你成为税务非居民的那天，可能是很多年前。

误区三：「房子不算离境税，就什么都不用管」。加拿大不动产离境时不视同出售，但你作为非居民出租或出售它时，另有预扣和申报规定。

误区四：「TFSA 留着继续存」。成为非居民后存入的部分按月加税，越晚发现代价越大。

误区五：「放弃 PR 会影响我的中国国籍和户口」。PR 不是外国国籍，放弃 PR 不改变中国国籍。来源 反倒是回国定居后，户口与社保怎么处理，要以户籍地的口径为准。

误区六：「先放弃，以后需要再申请回来」。重新移民没有便捷通道，放弃前要确定未来十年不需要这个身份。

要准备和保存的文件

移民：IMM 5782 签字原件副本、护照、枫叶卡、递交与确认记录。税务：离境日各项资产的公允市值证明（券商月结单、房产估价）、原始成本、RRSP 与 TFSA 年度结单、离境年及之后的税表、出租房产的租约与收支。生活：离开加拿大与在中国定居的证明，例如中国的住房、社保与医保缴费记录。

被问到这几个问题时，拿什么回答

CRA 问「你哪年成为非居民」：用离开加拿大的机票、杭州的住所与社保记录、本拿比公寓出租合同回答。CRA 问「离境时这些股票值多少」：用 2019 年 6、7 月的券商结单回答，找不到的尽早向券商申请历史结单。以后申请访客签证时被问「为什么放弃 PR」：如实说明已回国定居、主动了结身份，并附 IRCC 的确认文件。

什么情况必须找持牌专业人士

离境年没报税、名下有出租房产、公司股份、信托或大额证券，找跨境 CPA 或税务律师。PR 身份是否还有挽回空间、家庭成员身份不一致、或者放弃会影响配偶子女的申请，先找持牌移民律师或 RCIC。
